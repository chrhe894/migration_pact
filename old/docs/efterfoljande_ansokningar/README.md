# Efterföljande ansökningar

Den här mappen samlar dokumentation om efterföljande ansökningar enligt nya asylprocedurförordningen jämfört med äldre ordning.

Dokument:

- [Krav](krav.md) för ska- och börkrav med rättslig grund, område och kort motivering.
- [Aktivitetsflöde](aktivitetsflode.puml) som PlantUML-graf över klassificering, förhandsprövning, beslut och rätt att stanna.
- [User stories](user_stories.md)

Primär ny källa:

- Förordning (EU) 2024/1348, särskilt artikel 3.19, 38.2, 55, 56 och 68.

Primär gammal källa:

- Direktiv 2013/32/EU, särskilt artikel 2 q, 33.2 d och 40-42.
