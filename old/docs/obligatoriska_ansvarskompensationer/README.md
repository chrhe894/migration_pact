# Obligatoriska ansvarskompensationer

Den här mappen samlar kravanalys för ansvarskompensationer enligt solidaritetsmekanismen i förordning (EU) 2024/1351, med särskilt fokus på när ansvarskompensation blir obligatorisk eller ersätter ett outnyttjat omfördelningsåtagande.

Dokument:

- [Krav](krav.md) för ska- och börkrav med rättslig grund, område och kort motivering.
- [Begreppsflöde](begreppsflode.puml) som PlantUML-graf över vanligt asylärende, omfördelning, frivillig ansvarskompensation och obligatorisk ansvarskompensation.

Primär källa:

- Förordning (EU) 2024/1351, särskilt artiklarna 12, 13, 56, 57, 58-63, 66, 69, 70, 72-73 och 85.

Kopplade källor:

- Förordning (EU) 2024/1358, särskilt artikel 16.3 om att ange ansvarig medlemsstat i Eurodac.
- Förordning (EU) 2024/1348, särskilt artiklarna 55 och 56 när artikel 63.9 tillämpas för personer vars ansökan slutligt avslagits.
- Förordning (EU) 2024/1359 kan påverka ansvarskompensationer vid kris, instrumentalisering eller force majeure.

- Vilken svensk funktion ska äga avräkning mellan omfördelningslöften och ansvarskompensationer?
- Hur ska ett övertaget ansvar särskiljas från vanlig ansvarsöverföring enligt ansvarskriterierna?
- Vilka Eurodacuppdateringar ska automatiseras och vilka kräver manuell kontroll?
