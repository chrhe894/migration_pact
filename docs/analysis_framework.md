# Analysramverk

Det här ramverket är avsett för ren dokumentationsanalys av materialet om EU:s migrations- och asylpakt i `ref_material/`. Syftet är att hålla anteckningar spårbara, neutrala och användbara för senare rättslig, politisk eller operativ genomgång.

## Omfattning

Nuvarande omfattning:

- Förordning (EU) 2024/1348: gemensamt förfarande för internationellt skydd.
- Förordning (EU) 2024/1351: asyl- och migrationshantering, ansvarsfördelning och solidaritet.
- Förordning (EU) 2024/1359: åtgärder vid kris, instrumentalisering och force majeure.

Utanför omfattningen tills materialet läggs till i `docs/source_inventory.md`:

- Mottagningsvillkor, skyddsgrund, screening, Eurodac, återvändandeförfarande vid gränsen, vidarebosättning och genomförandeakter.
- Nationella genomförandeanvisningar eller operativa myndighetsmanualer.
- Rättspraxis, om den inte kopplas till en specifik artikel eller ett specifikt begrepp i källmaterialet.

## Mall för analysanteckning

Använd denna struktur för varje analysanteckning:

```markdown
# [Ämne]

## Källgrund

- Lokal källa: `ref_material/[fil].pdf`
- EU-rättsakt: Förordning (EU) [år]/[nummer]
- Artiklar/skäl som granskats: [lista]
- Officiell referens: [EUR-Lex-URL]

## Vad källan säger

Neutral sammanfattning av relevant regel, tröskel, procedur, skyldighet eller möjlighet till skönsmässig bedömning.

## Praktisk betydelse

Kort förklaring av vad som ändras i process, ansvar, tidsfrister, bevisning eller samordning.

## Beroenden

Andra rättsakter i pakten, genomförandebeslut, myndighetsroller, kapacitetsantaganden eller kopplade förfaranden.

## Öppna frågor

Punkter som kräver artikelkontroll, svensk nationell kontext, genomförandevägledning eller senare rättspraxis.
```

## Analysaxlar

Använd dessa axlar konsekvent så att anteckningar kan jämföras mellan rättsakterna:

| Axel | Frågor att besvara |
| --- | --- |
| Utlösande faktor | Vilken händelse, ansökan, pressnivå eller rättslig bedömning aktiverar regeln? |
| Aktör | Vilken myndighet, medlemsstat, EU-institution, byrå, sökande eller tredjeland agerar? |
| Tidslinje | Vilka tidsfrister, maxperioder, tillämpningsdatum eller granskningscykler spelar roll? |
| Rättigheter och skydd | Vilka processuella garantier, överklaganderättigheter, informationsskyldigheter, sårbarhetsbedömningar eller non-refoulement-krav gäller? |
| Ansvar | Vilken medlemsstat ansvarar, och hur kan ansvaret flyttas? |
| Solidaritet | Kopplas regeln till omfördelning, finansiella bidrag, operativt stöd eller avräkningar? |
| Undantag | Ändrar kris- eller force majeure-regler den ordinarie regeln? |
| Bevisning | Vilka informationskällor, bedömningar, garantier eller register krävs? |
| Genomföranderisk | Var kan kapacitet, samordning, datakvalitet eller skilda tolkningar påverka utfallet? |

## Rekommenderad läsordning

1. Börja med förordning (EU) 2024/1351 för att förstå hanteringsramen, ansvarsfördelningen och solidaritetsmekanismen.
2. Läs förordning (EU) 2024/1348 mot den ramen för att kartlägga ansökans processväg.
3. Läs förordning (EU) 2024/1359 sist och markera varje tillfälligt undantag mot den ordinarie regel som ändras.

## Citeringsregler

- Ange lokal PDF-fil och EU-rättsaktens nummer för varje sakpåstående.
- Använd artikelhänvisningar för operativa regler och skälhänvisningar för syfte eller tolkning.
- Markera osäkra punkter som `kräver verifiering` i stället för att jämna ut luckor.
- Håll sammanfattningar neutrala; dra inte slutsatser om policyeffekter utan tydlig källgrund.
