# Omfördelning

Den här mappen samlar dokumentation om omfördelning enligt den nya asyl- och migrationshanteringsförordningen. Fokus är kravanalys: vad som är nytt, vilka förändringsområden som kan identifieras och vilka användarberättelser som kan följa av processen.

Dokument:

- [Jämförelse](jamforelse.md) för gammal ordning jämfört med ny.
- [Datapunkter](datapunkter.md) för begrepp, händelser, tidsfrister och möjliga systemfält.
- [Krav](krav.md) för ska- och bör-krav med koppling till rättslig grund och user stories.
- [User stories](user_stories.md) för krav uttryckta som användarberättelser.

Primär ny källa:

- Förordning (EU) 2024/1351, särskilt artikel 12, 13, 15, 56-69, 70-72 och bilaga I.

Primär gammal källa:

- Förordning (EU) nr 604/2013, Dublin III, som upphävs av 2024/1351. Gammal ordning hade ansvarskriterier men inte samma permanenta solidaritetspool och omfördelningsförfarande.

Frågor att utreda:

- Vilken svensk roll är aktuell: bidragande medlemsstat, gynnad medlemsstat eller båda i olika lägen?
- Vilka nationella system ska äga uppgifter om utfästa solidaritetsbidrag, omfördelningsärenden och ansvarsövergång?
- Hur ska omfördelning samordnas med Eurodac, mottagning, asylprövning, säkerhetskontroll och överföringslogistik?
- Vilken intern rapportering behövs till kommissionen, EU-solidaritetssamordnaren och tekniska forum?
