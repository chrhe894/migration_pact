# Asylprocedurförordningen (APR)

## Fullständig titel

Europaparlamentets och rådets förordning (EU) 2024/XXX om ett gemensamt förfarande för internationellt skydd i unionen och om upphävande av direktiv 2013/32/EU.

---

## Kort beskrivning

APR ersätter det tidigare asylprocedurdirektivet (2013/32/EU) och inför ett direkt tillämpligt gemensamt förfarande för prövning av ansökningar om internationellt skydd i alla EU-medlemsstater.

---

## Viktiga nyheter jämfört med tidigare regelverk

- **Förordning istället för direktiv** — Direkt tillämplig, inget nationellt genomförande krävs.
- **Gränsförfarande** — Obligatoriskt vid vissa förutsättningar (art. 43–54).
- **Påskyndat förfarande** — Tydligare och bredare grunder (art. 42).
- **Efterföljande ansökningar** — Strängare regler vid andra eller följande ansökningar (art. 55–56).
- **Registrering, inlämnande, prövning** — Tre tydliga steg med separata tidsfrister.
- **Integration med AMMR** — Ansvarsbedömning och prövningsförfarande kopplas tydligare.
- **Rättsliga garantier** — Tydligare krav på tolkning, information, personlig intervju (art. 8–14).

---

## Struktur

| Del | Artiklar | Innehåll |
|-----|----------|----------|
| I | 1–7 | Allmänna bestämmelser, definitioner |
| II | 8–14 | Grundläggande principer och garantier |
| III | 15–33 | Förfaranden i första instans — registrering, inlämnande, information |
| IV | 34–42 | Prövning — admissibility, sak, påskyndat |
| V | 43–54 | Gränsförfarande och return border |
| VI | 55–56 | Efterföljande ansökningar |
| VII | 57–68 | Överklagande |
| VIII | 69– | Slutbestämmelser |

---

## Centrala tidsfrister

| Händelse | Frist |
|----------|-------|
| Registrering | 5 dagar (15 vid massinflöde, 4 veckor vid kris) |
| Inlämnande | 21 dagar (5 dagar vid gränsförfarande) |
| Prövning (reguljärt) | 6 månader (15 vid komplexitet) |
| Prövning (påskyndat) | 3 månader |
| Gränsförfarande | 12 veckor (18 vid kris) |
| Return border | 12 veckor |
