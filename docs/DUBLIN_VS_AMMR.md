# Dublin III vs AMMR — vad har ändrats?

## Syfte

Detta dokument jämför det gamla systemet (Dublin III-förordningen, 604/2013) med det nya (AMMR, 2024/1351) för att hjälpa läsare med befintlig kunskap att förstå förändringarna.

---

## Grundprincipen — kvarstår

Båda systemen bygger på principen att **en** medlemsstat ska vara ansvarig för att pröva en ansökan om internationellt skydd. Sökanden har inte rätt att välja stat.

---

## Vad har ändrats?

| Aspekt | Dublin III | AMMR |
|--------|-----------|------|
| **Tidsfrist för inresa-ansvar** | 12 månader | 20 månader (irreguljär passage) / 12 månader (landsättning) |
| **Framställan om övertagande** | 3 månader | 2 månader (1 mån vid Eurodac-träff) |
| **Svar på framställan** | 2 månader | 1 månad (2 veckor vid Eurodac-träff) |
| **Överföringsfrist** | 6 månader | 6 månader (oförändrat) |
| **Förlängd frist vid avvikande** | 18 månader | 18 månader (oförändrat) |
| **Examensbevis som kriterium** | Fanns inte | Nytt kriterium (art. 30) — max 6 år |
| **Nytt viseringsfritt kriterium** | Fanns inte | Nytt (art. 31) |
| **Tyst godkännande** | Existerade men svagare formulering | Förstärkt — inget svar = godkännande |
| **Solidaritetsmekanism** | Frivillig | Obligatorisk (art. 57–69) |
| **Ansvarskompensation** | Fanns inte | Nytt — obligatoriskt om omfördelning inte sker |
| **Screening före registrering** | Fanns inte | Obligatorisk screening (7 dagar) |
| **Gränsförfarande** | Valfritt | Obligatoriskt för vissa grupper (art. 45) |
| **Kapacitetsmekanism** | Fanns inte | 30 000 platser totalt (art. 46–50) |
| **Krishantering** | Separat temporärt instrument | Permanent förordning (2024/1359) |

---

## Vad kvarstår i princip?

- Kriteriehierarkin (familj → uppehållstillstånd → inresa)
- Familjeåterförening som högsta kriterium
- Ensamkommande barns särställning
- Diskretionär bedömning (suveränitetsklausulen)
- Take charge / take back-förfaranden
- Överföring med 6-månaderstidsfrist
- Konsekvens: missad frist = ansvar övergår

---

## Nytt som inte fanns i Dublin III

1. **Obligatorisk screening** — en helt ny fas före registrering
2. **Obligatoriskt gränsförfarande** — prövning utan inresa för vissa grupper
3. **Solidaritetspool** — årlig fördelning av bidrag baserat på referensnyckel
4. **Ansvarskompensationer** — alternativ till fysisk omfördelning
5. **Eurodac-utbyggnad** — ansiktsbild, fler kategorier, koppling till interoperabilitet
6. **Återvändande vid gräns** — egen förordning för återvändande vid gräns
7. **Examensbevis** som ansvarsgrund
8. **Kapacitetstak** som kan stänga av obligatoriskt gränsförfarande

---

## Praktiska konsekvenser

- **Snabbare förfarande** — kortare tidsfrister i varje steg.
- **Mindre valfrihet för stater** — obligatorisk screening, obligatoriskt gränsförfarande, obligatorisk solidaritet.
- **Starkare koppling till Eurodac** — systemet bygger i större utsträckning på databassökningar.
- **"Sanktionsmekanism" via tidsfrister** — den som inte agerar i tid förlorar eller får ansvar.
- **Solidaritet som motprestation** — stater som gynnas av gränsförfarandet förväntas bidra via poolen.
