# REQ-INT-002

## Krav

Kostnader för tolkning ska bäras av det allmänna. Sökanden ska inte belastas med kostnader för tolktjänster.

---

## Syfte

Garanterar att rätten till tolk är reell och ekonomiskt tillgänglig, inte enbart formell.
