# REQ-INT-003

## Krav

Tolken ska vara kvalificerad och neutral. Tolken ska kunna kommunicera på lämpligt sätt med den sökande och får inte ha någon intressekonflikt.

---

## Syfte

Säkerställer att tolkningens kvalitet och objektivitet upprätthålls, och att sökanden kan lita på att kommunikationen återges korrekt.
