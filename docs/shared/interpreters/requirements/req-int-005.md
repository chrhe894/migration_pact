# REQ-INT-005

## Krav

Tolken vid intervju ska möjliggöra effektiv kommunikation och sakna intressekonflikt.

---

## Syfte

Garanterar att tolkningens kvalitet upprätthålls och att tolken agerar opartiskt utan kopplingar till sökanden eller ärendet.
