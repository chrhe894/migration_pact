# REQ-INT-001

## Krav

Tolk ska tillhandahållas vid registrering, inlämnande och personlig intervju när ändamålsenlig kommunikation inte kan säkerställas utan tolktjänster.

---

## Syfte

Säkerställer att sökanden kan kommunicera effektivt vid de centrala stegen i asylförfarandet och att språkbarriärer inte hindrar en rättvis process.
