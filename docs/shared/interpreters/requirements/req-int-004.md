# REQ-INT-004

## Krav

Sökanden ska ges personlig intervju innan beslut i första instans.

---

## Syfte

Säkerställer att sökanden har möjlighet att muntligt redogöra för sina grunder innan beslut fattas, som ett led i en rättssäker prövning.
