# REQ-INT-006

## Krav

Sökanden får begära tolk av samma kön vid könsbaserat våld.

---

## Syfte

Möjliggör en tryggare intervjusituation för sökande som utsatts för könsbaserat våld genom att erbjuda valfrihet avseende tolkens kön.
