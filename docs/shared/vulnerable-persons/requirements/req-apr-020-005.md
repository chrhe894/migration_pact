# REQ-APR-020-005

## Krav

Relevant personal vid de behöriga myndigheterna och de yrkesutövare som ger rådgivning om behovet av särskilda förfarandegarantier ska få utbildning i att upptäcka tecken på sårbarhet och tillgodose behoven när de fastställts.

---

## Syfte

Bedömningen fungerar bara om personalen kan känna igen tecknen.
