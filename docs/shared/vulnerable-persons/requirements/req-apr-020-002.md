# REQ-APR-020-002

## Krav

Bedömningen ska inledas så snart som möjligt efter att ansökan gjorts, genom att första tecken på behov av särskilda förfarandegarantier identifieras. Uppgifter om första tecken ska föras in i sökandens akt vid registreringen och göras tillgängliga för den beslutande myndigheten. För underåriga ska även uttalanden från föräldrar, ansvarig vuxen eller företrädare beaktas.

---

## Syfte

Gör att behov som syns redan vid registreringen följer med ärendet till den beslutande myndigheten.
