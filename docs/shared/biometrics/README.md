# Delat — Biometri

## Syfte

Denna shared-modul dokumenterar regler och begrepp kring insamling, lagring och användning av biometriska uppgifter (fingeravtryck och ansiktsbild) som är gemensamma för flera domäner.

Biometriska uppgifter är centrala för hela systemet — de möjliggör identifiering, ansvarsbestämning och säkerhetskontroller.

## Personkategorier

Biometriska uppgifter ska tas för följande kategorier (från sex års ålder, [art. 13.1](../../domains/eurodac/articles/eur-013.md)):

| Kategori | Artikel | Tidsfrist för överföring | Lagring ([art. 29](../../domains/eurodac/articles/eur-029.md)) |
|----------|---------|--------------------------|------------------|
| Sökande av internationellt skydd | [art. 15](../../domains/eurodac/articles/eur-015.md) | 72 timmar från registrering av ansökan (vid gräns: från insamling) | 10 år |
| Inreseförfarande enligt unionsramen för vidarebosättning | [art. 18](../../domains/eurodac/articles/eur-018.md) | Före inresebeslut. Efter beslut: 72 timmar | Registreras inte (18.1). 5 år vid beviljat, 3 år vid vägrat eller avbrutet |
| Nationellt vidarebosättningsprogram | [art. 20](../../domains/eurodac/articles/eur-020.md) | 72 timmar från beviljat skydd eller status | 5 år |
| Irreguljär passage av yttre gräns | [art. 22](../../domains/eurodac/articles/eur-022.md) | 72 timmar från omhändertagandet (vid förvar över 72 h: före frigivning) | 5 år |
| Olaglig vistelse | [art. 23](../../domains/eurodac/articles/eur-023.md) | 72 timmar från konstaterandet | 5 år |
| Landsättning efter sök och räddning | [art. 24](../../domains/eurodac/articles/eur-024.md) | 72 timmar från landsättningen (+48 h vid plötslig tillströmning) | 5 år |
| Tillfälligt skydd | [art. 26](../../domains/eurodac/articles/eur-026.md) | Tio dagar från registreringen | 1 år, förlängs årligen |

Vid hälsorelaterade hinder gäller i regel 48 timmar efter att hindren undanröjts. Vid allvarliga tekniska problem får fristen förlängas med högst 48 timmar.

**Omfördelning** är ingen egen insamlingskategori. Befintligt dataset uppdateras med omfördelningsmedlemsstaten (25.1) och översänds med ankomstdatum (25.2), se [art. 25](../../domains/eurodac/articles/eur-025.md).

> **Rättelse:** tabellen angav tidigare fel artikel för flera kategorier. Den innehöll också en kategori för "återkallat uppehållstillstånd", som inte finns i Eurodacförordningen.

## Koppling till ansvarsbestämning

Biometrisk registrering i Eurodac kan utlösa ansvarsförfarande:
- En träff mot ett redan registrerat dataset kan identifiera vilken stat som är ansvarig (AMMR art. 33 — irreguljär inresa).
- Jämförelsen och träffen regleras i [Eurodac art. 27](../../domains/eurodac/articles/eur-027.md). Träffen ska kontrolleras av expert ([art. 38](../../domains/eurodac/articles/eur-038.md)).
- Brottsbekämpande jämförelse är möjlig under strikta villkor ([Eurodac art. 32–34](../../domains/eurodac/articles/eur-033.md)).
