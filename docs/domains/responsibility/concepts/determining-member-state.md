
# CON-RES-006

## Begrepp

Determining Member State

---

## Definition

Den medlemsstat som genomför förfarandet för att fastställa vilken stat som är ansvarig för att pröva en ansökan om internationellt skydd. Normalt den stat där ansökan först registrerades.
