# CON-EUR-004

## Begrepp

Facial image data

---

## Definition

Uppgifter om ansiktsbild som behandlas inom Eurodac.

---

## Syfte

Kompletterar fingeravtrycksuppgifter för att möjliggöra identifiering även när fingeravtryck inte kan tas eller jämföras framgångsrikt.

---

## Skapas av

Samlas in av den behöriga myndigheten genom fotografering av personens ansikte vid screenings- eller registreringsförfarandet ([PROC-EUR-001](../processes/collect-and-transmit-biometric-data.md)).

---

## Rättslig grund

[Eurodac artikel 17](../articles/eur-017.md), punkt 1 b; [Eurodac artikel 23](../articles/eur-023.md), punkt 2 b
