
# Solidarity

## Syfte

Domänen beskriver solidaritetsmekanismen i AMMR (del IV), inklusive den årliga solidaritetspoolen, omfördelning, ansvarskompensationer och ekonomiska bidrag.

Solidaritetsmekanismen syftar till att fördela ansvaret rättvist mellan medlemsstaterna vid migrationstryck.

## Juridiska milstolpar

```text
Migrationstryck konstateras
        │
        ▼
Solidaritetspoolen aktiveras (art. 57)
        │
        ├── Omfördelning (art. 67)
        ├── Ansvarskompensationer (art. 63)
        └── Ekonomiska bidrag (art. 64)
        │
        ▼
Omfördelning genomförs
        │
        ▼
Ansvar övergår till mottagande stat (art. 68)
```
