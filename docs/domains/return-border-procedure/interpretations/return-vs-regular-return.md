# Tolkning

## Frågeställning

Hur skiljer sig return border procedure från det ordinarie återvändandedirektivet?

---

## Analys

Återvändande vid gräns (förordning 2024/1349) och återvändandedirektivet (2008/115/EG) reglerar båda återvändande, men i olika situationer:

**Återvändande vid gräns:**
- Tillämpas *enbart* efter avslag i asylgränsförfarandet.
- Personen har *inte* tillåtits resa in — befinner sig vid gränsen.
- Tidsgräns: högst 12 veckor från att rätten att stanna kvar upphört (art. 4.2). Hinns återvändandet inte verkställas fortsätter det enligt återvändandedirektivet (art. 4.4). Förordningen ger ingen rätt till inresa.
- Personen vistas vid gränsen, i ett transitområde eller på annan anvisad plats. Vissa artiklar i återvändandedirektivet gäller även här (art. 4.3).

**Ordinarie återvändandedirektivet:**
- Tillämpas på tredjelandsmedborgare som vistas olagligt *på* territoriet.
- Ingen absolut tidsgräns för hela förfarandet (men förvarsgräns på 6+12 månader).
- Personen befinner sig redan på territoriet.
- Tillämpas efter screening inom territoriet (artikel 7) eller efter reguljärt asylförfarande.

**Praktisk konsekvens:** Återvändande vid gräns är designat för att förhindra att en person vars ansökan avslagits vid gränsen överhuvudtaget sätter fot på territoriet. Om tolvveckorsperioden passerar utan verkställighet fortsätter återvändandet enligt det ordinarie återvändandedirektivet (art. 4.4). Förvar räknas då in i direktivets maximala förvarsperioder (art. 5.4).

> **Rättelse:** tolkningen angav tidigare att inresa tillåts när tolv veckor passerat. Den regeln gäller gränsförfarandet för asyl (APR art. 51.2), och där görs ett uttryckligt undantag när art. 4 i förordning 2024/1349 är tillämplig.
