# ART-RET-007

## Artikel

Return Border Procedure artikel 7

## Rubrik

Förvar

## Sammanfattning

Reglerar villkoren för förvar under return border procedure. Förvar ska vara proportionellt, tidsbegränsat och grundas på individuell bedömning.
