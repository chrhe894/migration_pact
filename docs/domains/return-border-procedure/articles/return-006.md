# ART-RET-006

## Artikel

Återvändande vid gräns artikel 6

## Rubrik

Rättsmedel

---

## Sammanfattning

Artikeln fastställer rätten till rättsmedel mot återvändandebeslutet inom return border procedure.

---

## Innehåll

Personen har rätt till överklagande. Suspensiv verkan kan beviljas av domstol. Tidsfristerna för avlägsnande fryses under pågående domstolsprövning med suspensiv verkan.
