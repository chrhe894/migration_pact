# ART-RET-004

## Artikel

Återvändande vid gräns artikel 4

## Rubrik

Tillämpning av återvändandegränsförfarandet

---

## Sammanfattning

Artikeln fastställer att förfarandet ska tillämpas på personer som inte har rätt att stanna efter att deras ansökan avslagits eller avvisats i gränsförfarandet, och som inte har tillåtits resa in.
