# ART-RET-008

## Artikel

Återvändande vid gräns artikel 8 (förordning (EU) 2024/1349)

## Rubrik

Särskilda bestämmelser och garantier

---

## Sammanfattning

Artikeln kräver att de berörda informeras när krisundantagen tillämpas.

---

## Innehåll

En medlemsstat som tillämpar undantagen i [art. 6](return-006.md) ska i vederbörlig ordning informera de berörda tredjelandsmedborgarna eller statslösa personerna om åtgärderna och deras **varaktighet**. Informationen ska ges på ett språk som de förstår eller rimligen kan förväntas förstå.
