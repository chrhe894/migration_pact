
# ART-RET-005

## Artikel

Return Border Procedure artikel 5

## Rubrik

Varaktighet

---

## Sammanfattning

Artikeln fastställer att return border procedure inte får pågå längre än tolv veckor efter att asylgränsförfarandet avslutats. Om avlägsnande inte verkställts inom den tiden ska personen tillåtas resa in.
