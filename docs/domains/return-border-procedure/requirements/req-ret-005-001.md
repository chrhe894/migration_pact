# REQ-RET-005-001

## Krav

Förvar får användas endast som sista utväg efter individuell bedömning, och förvarsperioden får inte överstiga tolvveckorsperioden i art. 4.2 (art. 5.1 och 5.4).

---

## Syfte

Begränsa frihetsberövandet till det som är nödvändigt för att förhindra inresa och genomföra återvändandet.
