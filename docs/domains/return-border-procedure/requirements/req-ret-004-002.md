# REQ-RET-004-002

## Krav

Personen ska vistas på anvisad plats i högst tolv veckor, räknat från den dag han eller hon inte längre har rätt att stanna kvar och inte tillåts stanna kvar (art. 4.2).

---

## Syfte

Säkerställa att tolvveckorsperioden får rätt startpunkt. Ett överklagande som ger rätt att stanna kvar skjuter upp starten, och perioden fryses inte.
