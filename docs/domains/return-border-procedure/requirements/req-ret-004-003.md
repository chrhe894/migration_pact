# REQ-RET-004-003

## Krav

Om beslutet om återvändande inte har verkställts inom tolvveckorsperioden ska återvändandeförfarandet fortsätta enligt återvändandedirektivet 2008/115/EG (art. 4.4).

---

## Syfte

Säkerställa kontinuitet i återvändandet efter att gränsförfarandet för återvändande upphört. Förordningen ger ingen rätt till inresa när perioden löpt ut.
