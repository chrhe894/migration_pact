# CAP-RET-001

## Verksamhetsförmåga

Conduct Återvändande vid gräns

---

## Syfte

Genomföra gränsförfarandet för återvändande efter avslag i gränsförfarandet för asyl, inom högst 12 veckor från att rätten att stanna kvar upphört.
