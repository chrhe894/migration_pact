
# Return Border Procedure

## Syfte

Domänen beskriver förordning (EU) 2024/1349 om återvändandegränsförfarandet (return border procedure) som tillämpas efter att en asylansökan avslagits i gränsförfarandet.

Återvändandegränsförfarandet säkerställer att personer vars ansökan avslagits i gränsförfarandet inte tillåts resa in på territoriet utan istället återvänder direkt.

---

## Plats i livscykeln

| | |
|---|---|
| **Föregående** | [Border Procedure](../border-procedure/README.md) (avslag i gränsförfarande) |
| **Nästa** | Verkställt avlägsnande, eller inresa tillåts (om 12v utan verkställighet) |
| **Inträde** | Avslag i asylgränsförfarande, person har inte rätt att stanna |
| **Utträde** | Person har återvänt eller tidsfrist löpt ut |

## Juridiska milstolpar

```text
Avslag i gränsförfarande (APR art. 44)
        │
        ▼
Return border procedure inleds
        │
        ├── Återvändandebeslut meddelas
        ├── Tidsfrist för frivillig avresa (max 15 dagar)
        ├── Överklagande (suspensiv verkan möjlig)
        │
        ▼
Verkställt avlägsnande eller frivillig avresa
```
