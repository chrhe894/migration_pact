# CAP-REG-003

## Verksamhetsförmåga

Lodge Application

---

## Syfte

Ta emot sökandens formella inlämnande av ansökan och starta prövningstidsfristen.

## Producerar

- Inlämnad ansökan (juridisk milstolpe: Application lodged)
- Prövningstidsfristen börjar löpa

## Konsumerar

- Registrerad ansökan
- Sökandens personliga närvaro (eller formulär vid undantag)
- Faktorer och handlingar som sökanden åberopar
