# REQ-APR-029-007

## Krav

Registreringshandling behöver inte tillhandahållas om sökandehandlingen kan utfärdas redan vid registreringen.

---

## Syfte

Undviker onödig dubbelutfärdning av handlingar när sökanden direkt kan erhålla den mer fullständiga sökandehandlingen.
