# REQ-APR-027-002

## Krav

Sökandens identitetsuppgifter (namn, födelsedatum, kön, medborgarskap) ska registreras.

---

## Syfte

Säkerställer att personen kan identifieras genom hela förfarandet och att Eurodac-dataset kan skapas.
