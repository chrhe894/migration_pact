# REQ-APR-027-013

## Krav

Beslutande myndighet eller annan myndighet som bistår denna får vid registreringen samla in ytterligare uppgifter som krävs för prövningen.

---

## Syfte

Möjliggör att nödvändiga uppgifter för prövningen samlas in redan vid registreringen utan att kräva ytterligare kontakter med sökanden.
