# REQ-APR-028-007

## Krav

Beslutande myndigheten ska underrättas utan dröjsmål om ansökan inte lämnas in direkt till den.

---

## Syfte

Säkerställer att den beslutande myndigheten kan inleda prövning utan onödig fördröjning.
