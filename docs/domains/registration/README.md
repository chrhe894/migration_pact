
# Registrering

## Syfte

Domänen beskriver registreringen av en ansökan om internationellt skydd enligt Asylum Procedure Regulation (APR).

Registreringen är den första formella delen av asylförfarandet och säkerställer att en ansökan dokumenteras, att sökanden får tillgång till de rättigheter som följer av unionsrätten och att ärendet kan handläggas vidare.

## Juridiska milstolpar

```text
Ansökan görs
        │
        ▼
Ansökan registreras  ──→  Registreringshandling utfärdas
        │
        ▼
Ansökan lämnas in  ──→  Sökandehandling utfärdas
        │
        ▼
Överföring till tillämpligt förfarande
```
