# REQ-RR-002-004

## Krav

Straffrättsliga förfaranden och påföljder för olaglig vistelse ska hanteras så att de inte hindrar eller fördröjer verkställigheten av återvändandet. Systemstödet ska göra det möjligt att samordna parallella straffrättsliga och återvändandeförfaranden.

---

## Syfte

Undvika att straffprocessen äventyrar effektivt återvändande.
