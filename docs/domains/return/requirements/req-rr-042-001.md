# REQ-RR-042-001

## Krav

Behöriga myndigheter ska som allmän regel samarbeta och stödja varandra i fråga om transitering, logistiskt stöd, överföring enligt art. 6.1 b och avresa enligt art. 6.3 (art. 42.1). Samarbete får också ske om politisk dialog med tredjeländer, identitetsverifiering, praktiska arrangemang och logistiskt stöd (art. 42.2).

---

## Syfte

Ge ett praktiskt samarbete mellan medlemsstaterna som underlättar att återvändande kan genomföras.
