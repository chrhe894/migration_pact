# REQ-RR-006-001

## Krav

Systemet ska kunna registrera att beslut om återvändande inte utfärdats med hänvisning till art. 6.1 a, b eller c, och ska för fall c inte fördröja personens avresa.

---

## Syfte

Spåra beslut att avstå och stödja snabb avresa.
