# REQ-RR-024-001

## Krav

Myndigheterna ska informera personer som är föremål för återvändande om förfarandets syfte, skyldigheter och konsekvenser, rådgivning och program samt processuella rättigheter. Informationen ska lämnas utan oskäligt dröjsmål på ett språk personen förstår, och vid flera återvändandeländer ska personen informeras om det aktuella landet i tillräckligt god tid före avlägsnandet (art. 24.1–3).

---

## Syfte

Säkerställa att personen förstår förfarandet och kan tillvarata sina rättigheter.
