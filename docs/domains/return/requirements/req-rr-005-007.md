# REQ-RR-005-007

## Krav

Beslutsmallen ska innehålla fält för faktiska omständigheter, rättsliga omständigheter, rättsmedel och tidsfrister för dem. Systemet ska registrera tidpunkt och sätt för underrättelse, inklusive underrättelse enligt nationell rätt när vistelseorten är okänd.

---

## Syfte

Säkerställa rättssäkra och spårbara beslut.
