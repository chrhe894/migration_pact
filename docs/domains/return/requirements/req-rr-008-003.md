# REQ-RR-008-003

## Krav

Systemet ska säkerställa att inreseförbud utfärdas skriftligen, antingen som del av beslutet om återvändande eller avlägsnande eller separat, och att underrättelse sker på ett språk som personen förstår eller rimligen kan förväntas förstå, med möjlighet att använda mallar eller datorstödd översättning.

## Syfte

Rättssäker underrättelse.
