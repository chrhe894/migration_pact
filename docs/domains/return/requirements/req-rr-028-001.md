# REQ-RR-028-001

## Krav

Den behöriga domstolen i första instans ska kunna skjuta upp avlägsnande på begäran under överklagandefristen eller under pågående överklagande, och ex officio om nationell rätt föreskriver det (art. 28.1–28.2). Vid ytterligare överklaganden ska avlägsnandet bara skjutas upp om nationell rätt föreskriver det eller en domstol beslutar det efter begäran (art. 28.3).
