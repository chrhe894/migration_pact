# REQ-RR-033-001

## Krav

Ensamkommande barn och familjer med underåriga ska hållas i förvar endast som sista utväg och för kortast lämpliga tid, med separat inkvartering, utbildad personal samt tillgång till fritidsverksamhet och undervisning (art. 33.1–33.3).

---

## Syfte

Skydda barn i förvar.
