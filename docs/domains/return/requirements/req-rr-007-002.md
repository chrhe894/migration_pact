# REQ-RR-007-002

## Krav

När den verkställande medlemsstaten inte erkänner eller verkställer ett beslut från annan medlemsstat ska systemet stödja utfärdande av ett eget beslut om återvändande enligt artikel 5 eller beslut om avlägsnande enligt artikel 10.3.

---

## Syfte

Garantera att det finns ett giltigt beslut att verkställa.
