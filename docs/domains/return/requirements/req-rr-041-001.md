# REQ-RR-041-001

## Krav

Varje medlemsstat ska enligt nationell rätt utse de behöriga myndigheter som ansvarar för att fullgöra skyldigheterna i förordningen (art. 41). Artikeln tillämpas från 16 oktober 2026.

---

## Syfte

Ge varje medlemsstat utpekade ansvariga myndigheter för förordningens skyldigheter.
