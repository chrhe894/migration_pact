# REQ-RR-008-007

## Krav

Systemet ska registrera datum då tredjelandsmedborgaren lämnade medlemsstaternas territorium och ska beräkna inreseförbudets slutdatum från den dagen.

---

## Syfte

Rätt beräkning av förbudets längd.
