# REQ-RR-009-001

## Krav

Systemet ska kunna registrera och pröva en begäran om återkallelse, tillfälligt upphävande eller förkortning av inreseförbud när personen visar att frivilligt återvändande skett, och spara beslutet.

---

## Syfte

Hantera ändring av förbud vid frivilligt återvändande.
