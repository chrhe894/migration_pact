# REQ-RR-027-002

## Krav

Inreseförbud och beslut om avlägsnande som utfärdas tillsammans med ett återvändandebeslut enligt art. 5.12 ska överklagas gemensamt inom samma frister. Separat utfärdade beslut får överklagas separat (art. 27.4). Vid återvändandebeslut som grundar sig på ett beslut om laglig vistelse får den nationella fristen för det beslutet tillämpas (art. 27.3).

---

## Syfte

Samordna överklaganden av sammanhängande beslut.
