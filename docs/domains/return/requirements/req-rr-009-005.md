# REQ-RR-009-005

## Krav

Systemet ska kunna registrera ett villkor om återbetalning av avlägsnandekostnader för återkallelse av inreseförbud, om medlemsstaten har valt att tillämpa det.

---

## Syfte

Hantera kostnadsvillkor.
