# REQ-RR-002-002

## Krav

Systemet ska kunna hålla reda på vilka av kategorierna i art. 2.4 a, b och c som medlemsstaten har beslutat att omfatta, och från vilket datum (dagen för underrättelsen till övriga medlemsstater och kommissionen). För kategorin i art. 2.4 c ska artiklarna 5, 7 och 8 inte tillämpas.

---

## Syfte

Säkerställa att förordningen tillämpas på utvidgade kategorier först från rätt datum.
