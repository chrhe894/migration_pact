# REQ-RR-008-005

## Krav

Systemet ska kunna registrera ett beslut att avstå från inreseförbud med angivande av skäl (humanitära skäl, människohandel eller samarbete, inklusive anmälan till program för återvändande och återintegrering).

---

## Syfte

Dokumentera undantag från förbud.
