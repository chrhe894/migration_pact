# REQ-RR-025-001

## Krav

Vid överklagande till domstol ska personen på begäran få nödvändigt kostnadsfritt rättsligt bistånd och biträde, med de undantag som art. 25.4 tillåter. Ensamkommande barn ska biträdas. Nekande från icke-domstol på grund av bristande utsikter ska kunna överklagas till domstol (art. 25.1–9).

---

## Syfte

Ge tillgång till effektiv domstolsprövning oavsett ekonomiska förutsättningar.
