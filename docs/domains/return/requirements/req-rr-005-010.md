# REQ-RR-005-010

## Krav

Systemet ska kunna registrera begäran om översättning, vilket språk som tillhandahållits, form (skriftlig eller muntlig) och om mall eller datorstödd översättning använts.

---

## Syfte

Spåra att översättning lämnats.
