# REQ-RR-044-001

## Krav

Medlemsstaterna ska säkerställa tillgång till rådgivning om återvändande och återintegrering så tidigt som möjligt (art. 44.1), lämna information om återvändande och återintegrering senast när beslutet om återvändande utfärdas (art. 44.2) och säkerställa tillgång till program för återvändande och återintegrering (art. 44.3). Stödet ska inte behandlas som en individuell rättighet eller som villkor för återtagandet (art. 44.4), ska spegla personens samarbete och kan minskas eller dras in (art. 44.5), och får inte ges till den som redan fått samma eller annat stöd (art. 44.6).

---

## Syfte

Ge tidig vägledning och stöd för återvändande och återintegrering utan att skapa en individuell rätt till stöd.
