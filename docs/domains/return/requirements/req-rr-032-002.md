# REQ-RR-032-002

## Krav

Juridiska ombud, familjemedlemmar, konsulära myndigheter och relevanta organisationer ska kunna besöka förvarsanläggningar (art. 32.5). Förstärkta säkerhetsarrangemang får användas för personer som utgör säkerhetsrisk endast så länge det är strikt nödvändigt (art. 32.7).

---

## Syfte

Ge insyn och proportionerlig säkerhet.
