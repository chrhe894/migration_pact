# REQ-RR-035-001

## Krav

Vid konstaterade brister i ett tredjelands samarbete, eller svårigheter i samarbetet om återtagande, ska unionen och medlemsstaterna vidta lämpliga åtgärder, inklusive villkorlighet inom relevanta politikområden (art. 35).

---

## Syfte

Stärka samarbetet med tredjeländer om återtagande.
