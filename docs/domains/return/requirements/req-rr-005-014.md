# REQ-RR-005-014

## Krav

Verksamheten ska påbörja rättsliga och tekniska arrangemang för att göra den europeiska återvändandeordern tillgänglig via Schengens informationssystem senast den dag genomförandeakten antas, och ska underrätta kommissionen om genomförda arrangemang senast 17 oktober 2027.

---

## Syfte

Uppfylla införandetidtabellen för den europeiska återvändandeordern.
