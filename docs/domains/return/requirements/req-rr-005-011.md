# REQ-RR-005-011

## Krav

Systemet ska koppla ett beslut om återvändande till det beslut som avslutar den lagliga vistelsen, och ska kunna utfärda dem i samma akt. Om beslutet om återvändande utfärdas separat ska tidsintervallet mellan de två besluten registreras så att dröjsmål kan följas upp.

---

## Syfte

Säkerställa att beslut om återvändande följer direkt på avslutad laglig vistelse.
