# REQ-RR-008-002

## Krav

Systemet ska göra det möjligt att utfärda ett inreseförbud tillsammans med ett beslut om återvändande eller avlägsnande även i andra fall än art. 8.1, med dokumentation av relevanta omständigheter, särskilt samarbete.
