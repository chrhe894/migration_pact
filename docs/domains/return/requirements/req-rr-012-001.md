# REQ-RR-012-001

## Krav

Medlemsstaten ska ha ett oberoende system för övervakning av avlägsnanden (art. 12). Befintliga mekanismer enligt förordning (EU) 2024/1356 får användas.

---

## Syfte

Möjliggöra oberoende insyn i genomförandet av avlägsnanden.
