# REQ-RR-029-002

## Krav

Beslut om förvar ska vara skriftligt, innehålla faktiska och rättsliga omständigheter och information om rättsmedel samt meddelas på ett språk personen förstår (art. 29.4).

---

## Syfte

Säkerställa att förvarsbeslutet kan förstås och angripas.
