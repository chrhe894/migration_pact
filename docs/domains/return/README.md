# Återvändande

## Syfte

Domänen beskriver **förordning (EU) 2026/2280** om ett gemensamt system för återvändande av tredjelandsmedborgare vars vistelse i unionen är olaglig. Förordningen ersätter återvändandedirektivet 2008/115/EG, direktiv 2001/40/EG och beslut 2004/191/EG.

Domänen omfattar beslut om återvändande och tidsfrist för avresa, ömsesidigt erkännande, inreseförbud, avlägsnande, barn, skyldighet att samarbeta, risk för avvikande, rättsmedel, förvar, återtagande och samarbete med tredjeländer.

> **Tillämpning.** Förordningen trädde i kraft **16 oktober 2026**. Bara vissa artiklar tillämpas redan (art. 50.2). De flesta bestämmelserna tillämpas från **17 oktober 2027**, och **fram till dess gäller direktiv 2008/115/EG** och utlänningslagen. Se [Övergången 2026–2027](interpretations/transition-2026-2027.md).

## Juridiska milstolpar

```text
Olaglig vistelse
        │
        ├── Undantag (art. 6): överföring, utresekontroll, tillstånd i annan MS
        ├── Erkännande av annan MS beslut (art. 7)
        ▼
Beslut om återvändande (art. 5) + ev. inreseförbud (art. 8)
   Tidsfrist för avresa högst 30 dagar, eller omedelbart
        │
        ├── Överklagande högst 14 dagar, ingen automatisk suspensiv verkan (art. 27–28)
        ├── Samarbete, risk för avvikande, tillgänglighet (art. 18–23)
        ▼
Frivilligt återvändande ──► inreseförbudet löper från avresedagen (art. 8.9)
   eller
Förvar (art. 29–33) → återtagande (art. 34) → avlägsnande (art. 10)
   eller
Uppskjutet avlägsnande (art. 11)
```
