# CON-RTN-006

## Begrepp

Removal (avlägsnande)

---

## Definition

De behöriga myndigheternas verkställande av ett beslut om återvändande eller ett beslut om avlägsnande genom **faktisk transport** från medlemsstaterna till ett återvändandeland ([art. 3.7](../articles/rr-003.md)). Ett **beslut om avlägsnande** fastställer eller förklarar att personen kan avlägsnas till ett eller flera återvändandeländer ([art. 3.6](../articles/rr-003.md)).
