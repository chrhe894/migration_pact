# CON-RTN-003

## Begrepp

European Return Order (europeisk återvändandeorder)

---

## Definition

Ett gemensamt formulär som innehåller de huvudsakliga delarna av beslutet om återvändande och, i förekommande fall, beslutet om avlägsnande ([art. 5.13](../articles/rr-005.md)).

---

## Regler och datum

| Vad | Datum eller krav | Regel |
|-----|------------------|-------|
| Kommissionen antar formuläret genom en genomförandeakt | Senast **17 april 2027** | [RULE-RR-005-013](../rules/rule-rr-005-013.md) |
| Medlemsstaterna, kommissionen och eu-LISA börjar införa rättsliga och tekniska arrangemang för SIS | Senast den dag genomförandeakten antas | [RULE-RR-005-014](../rules/rule-rr-005-014.md) |
| Medlemsstaterna använder ordern och gör den tillgänglig via SIS | Från **17 oktober 2027** | [RULE-RR-005-012](../rules/rule-rr-005-012.md) |
| Automatiserad hantering möjlig (kommissionen och byråer), och medlemsstaterna underrättar om sina arrangemang | Senast **17 oktober 2027** | [RULE-RR-005-014](../rules/rule-rr-005-014.md) |

Ordern är också underlaget när en annan medlemsstat erkänner och verkställer beslutet ([art. 7](../articles/rr-007.md), [PROC-RTN-003](../processes/recognition-of-return-decision.md)).
