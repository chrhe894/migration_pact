# PROC-RTN-006

# Frivilligt återvändande med stöd

Delprocess till [PROC-RTN-001 Återvändandeförfarande](return-procedure.md), steg 5 och 9.

## Trigger

Ett beslut om återvändande med tidsfrist för avresa har utfärdats, och personen kan eller vill återvända på egen hand.

---

## Resultat

Personen har lämnat territoriet inom, eller efter utgången av, tidsfristen ([art. 3.8](../articles/rr-003.md)). Avresan är registrerad. Om personen inte reser går ärendet till [PROC-RTN-005](return-coordination-travel.md).

---
