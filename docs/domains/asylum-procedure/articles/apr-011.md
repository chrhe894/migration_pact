# ART-APR-011

## Artikel

APR artikel 11

## Rubrik

Intervju för att underlätta fastställandet av ansvarig stat

---

## Sammanfattning

Reglerar den personliga intervjun som genomförs för att identifiera omständigheter som kan avgöra ansvarig stat (AMMR-kriterier).

---

## Innehåll

Intervjun ska genomföras så snart som möjligt efter registrering. Syftet är att inhämta uppgifter om familjemedlemmar, uppehållstillstånd, resvägar etc. som behövs för ansvarsbedömningen.
