# REQ-APR-056-003

## Krav

Antalet efterföljande ansökningar ska hållas räknat så att nivån (första respektive andra eller följande) kan avgöra om undantag från rätten att stanna kvar kan tillämpas.

---

## Syfte

Säkerställa korrekt bedömning av rätten att stanna, eftersom undantag enligt artikel 56 endast gäller vid andra eller följande efterföljande ansökan.
