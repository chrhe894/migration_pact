# REQ-APR-055-004

## Krav

Vid första efterföljande ansökan har sökanden som huvudregel rätt att stanna. Undantag får göras endast om ansökan lämnats in enbart för att försena eller hindra ett omedelbart avlägsnande och inte prövas vidare enligt artikel 55.7.

---

## Syfte

Skydda sökanden mot avlägsnande under pågående prövning av den första efterföljande ansökan, utom vid ansökningar som enbart syftar till att fördröja.
