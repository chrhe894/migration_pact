
# Kris

## Syfte

Domänen beskriver krishanteringsförordningen (EU) 2024/1359 som fastställer särskilda regler vid kris- och force majeure-situationer i migrations- och asylområdet.

Förordningen medger undantag från ordinarie tidsfrister och förfaranden samt aktiverar förstärkta solidaritetsmekanismer.

---

## Plats i livscykeln

| | |
|---|---|
| **Föregående** | Alla domäner (krishantering kan aktiveras parallellt) |
| **Nästa** | Ordinarie förfaranden återupptas när kris upphör |
| **Inträde** | Medlemsstat begär krisförklaring, kommissionen fastställer |
| **Utträde** | Rådets beslut upphör, undantagsbestämmelser avaktiveras |

## Juridiska milstolpar

```text
Medlemsstat begär krisförklaring (art. 2)
        │
        ▼
Kommissionen fastställer kris- eller force majeure-situation (art. 3)
        │
        ▼
Rådet godkänner undantag och solidaritetsåtgärder (art. 4)
        │
        ▼
Undantag tillämpas (tidsfrister, gränsförfarande, registrering)
```
