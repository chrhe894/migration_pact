# REQ-SCR-005-002

## Krav

Screening ska genomföras för asylsökande vid gränsövergångsställen som ej uppfyller inresevillkoren.

---

## Syfte

Säkerställa att asylsökande som inte uppfyller inresevillkor genomgår screening innan vidare förfarande.
