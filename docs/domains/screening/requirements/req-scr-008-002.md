# REQ-SCR-008-002

## Krav

Vid uppehåll >72h vid gränsen förkortas screeningperioden till 4 dagar.

---

## Syfte

Säkerställa att den sammanlagda screeningtiden inte överskrider 7 dagar räknat från omhändertagande.
