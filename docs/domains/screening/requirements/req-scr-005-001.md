# REQ-SCR-005-001

## Krav

Screening ska genomföras för alla som omhändertas vid otillåten gränspassage eller landsätts.

---

## Syfte

Säkerställa att alla tredjelandsmedborgare som passerar yttre gräns utan tillstånd genomgår screening.
