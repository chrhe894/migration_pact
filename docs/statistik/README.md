# Statistik

Den här mappen samlar dokumentation om nya statistik- och rapporteringskrav jämfört med äldre ordning.

Dokument:

- [Eurodac och statistik](eurodac.md)
- [Jämförelse](jamforelse.md) för gammalt jämfört med nytt.
- [User stories](user_stories.md) för krav uttryckta som användarberättelser.
- [Datapunkter](datapunkter.md) för begrepp, mätpunkter, frekvenser och möjliga systemfält.

Frågor att utreda:

- Vilken statistik är ny eller mer detaljerad i den nya pakten?
- Vilka datapunkter behöver samlas in tidigare i processen än idag?
- Vilka uppgifter ska rapporteras nationellt respektive till EU-nivå?
- Finns krav på frekvens, format, uppdelning eller kvalitetssäkring?
