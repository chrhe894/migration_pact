# Return Border Procedure Regulation

## Officiell titel

Regulation (EU) 2024/1349 establishing a return border procedure.

---

## Förkortning

Return Border Procedure

---

## Syfte

Fastställer regler för återvändandeförfarandet vid den yttre gränsen efter ett avslutat gränsförfarande.

---

## Omfattning

Denna rättsakt reglerar bland annat:

- återvändandebeslut
- verkställighet
- frihetsberövande
- tidsfrister
