# Shared — Security checks

## Syfte

Denna shared-modul dokumenterar den säkerhetskontroll som ska genomföras under screening och som innebär sökningar mot EU-databaser och andra informationssystem.

---

## Primära rättskällor

- [Screeningförordningen artikel 15](../../domains/screening/articles/scr-015.md) — Säkerhetskontroll
- [Screeningförordningen artikel 16](../../domains/screening/articles/scr-016.md) — Åtgärder för identifiering och säkerhetskontroller

---

## Begrepp

- Security check — kontroll för att verifiera om en person utgör ett hot mot den inre säkerheten

---

## Databaser som söks

- SIS (Schengens informationssystem)
- EES (in- och utresesystemet)
- ETIAS (EU-systemet för reseuppgifter och resetillstånd) inkl. bevakningslista
- VIS (informationssystemet för viseringar)
- Ecris-TCN (fällande domar mot tredjelandsmedborgare)
- Europoluppgifter
- Interpols databaser
- Relevanta nationella databaser
