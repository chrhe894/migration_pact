# Shared — Time limits

## Syfte

Denna shared-modul samlar tidsfrister som regleras i APR och som är relevanta för flera domäner och processer.

---

## Primära rättskällor

- APR artikel 27 — Tidsfrister för registrering
- APR artikel 28 — Tidsfrister för inlämnande

---

## Regler

- RULE-TL-REG-001 — Registrering inom fem dagar
- RULE-TL-REG-002 — Registrering inom 15 dagar vid massinflöde
- RULE-TL-REG-003 — Underrättelse inom tre arbetsdagar vid fel myndighet
- RULE-TL-LOD-001 — Inlämnande inom 21 dagar från registrering
- RULE-TL-LOD-002 — Inlämnande inom två månader vid massinflöde

---

## Används av

- PROC-REG-001 Registration of an application
- PROC-REG-002 Lodging an application
