# Shared — Interpreters

## Syfte

Denna shared-modul dokumenterar rätten till tolktjänster under förfarandet för internationellt skydd.

Rätten till tolk är en grundläggande garanti som gäller i flera förfaranden och domäner.

---

## Primära rättskällor

- APR artikel 8.3 — Rätt till tolkning vid registrering, inlämnande och personlig intervju
- APR artikel 30.2 — Tolktjänster i förvarsanläggningar och vid gränsövergångsställen
