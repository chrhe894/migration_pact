# PlantUML-diagram

Lägg PlantUML-filer i den här mappen med filändelsen `.puml`.

Föreslagen start:

- `processkedja.puml` för övergripande processflöde.
- `ansvar_och_solidaritet.puml` för kopplingen mellan ansvarig medlemsstat och solidaritetsmekanismen.
- `krisundantag.puml` för hur kris- och force majeure-regler påverkar ordinarie förfarande.
